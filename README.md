## Introduction

Valet *Linux+* is a fast, lightweight PHP development environment for Linux. It keeps Nginx running in the background and uses [DnsMasq](https://en.wikipedia.org/wiki/Dnsmasq) to route every `*.test` domain to sites on your machine. No Vagrant, no `/etc/hosts`.

## About this fork

This project is a fork of [genesisweb/valet-linux-plus](https://github.com/genesisweb/valet-linux-plus), **actively maintained on a daily basis**. It is published on Packagist as [`fernandoebert/valet-linux-plus`](https://packagist.org/packages/fernandoebert/valet-linux-plus).

Issues and pull requests: [FernandoEbert/valet-linux-plus](https://github.com/FernandoEbert/valet-linux-plus).
